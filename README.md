# Платформа для адаптации первокурсников

Учебное веб-приложение, разработанное в рамках университетской производственной практики. Позволяет первокурсникам задавать анонимные вопросы, получать ответы от наставников и читать истории адаптации к университетской жизни.

## Функциональность

- Создание анонимных вопросов без регистрации
- Публикация вопросов после одобрения администратором
- Авторизация наставников и администраторов
- Ответы наставников на опубликованные вопросы
- Создание и просмотр историй адаптации
- Отправка жалоб на вопросы, ответы и истории
- Панель администратора для модерации вопросов и обработки жалоб

## Стек технологий

- **Frontend:** JavaScript, React, React Router, HTML/CSS, Vite
- **Backend:** Node.js, Express
- **База данных:** SQLite
- **Работа с базой данных:** Prisma ORM и миграции
- **Авторизация:** JWT, хеширование паролей с помощью bcryptjs

## Архитектура

Приложение разделено на клиентскую и серверную части:

- `frontend/` — React-приложение с формами, страницами и маршрутизацией.
- `backend/` — HTTP API на Express, проверка входных данных, авторизация и обработка запросов.
- `backend/prisma/` — схема базы данных и миграции.

Клиент взаимодействует с сервером через HTTP-запросы с помощью `fetch`. Данные передаются в формате JSON. Сервер выполняет операции с базой данных через Prisma.

## Доступ и модерация

В приложении предусмотрены три уровня доступа:

- **Гость:** просмотр материалов, создание анонимных вопросов и отправка жалоб.
- **Наставник:** ответы на вопросы и публикация историй.
- **Администратор:** одобрение и отклонение вопросов, обработка жалоб и скрытие материалов.

Новые вопросы сохраняются со статусом `PENDING`. После одобрения статус меняется на `APPROVED`, и вопрос становится доступен в публичном списке. Доступ к защищённым операциям проверяется на сервере по JWT и роли пользователя.
